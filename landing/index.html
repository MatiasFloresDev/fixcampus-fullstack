Privacidad del prototipo

El prototipo almacena nombre, correo, rol, incidencias e historial para gestionar la atención. La sesión usa una cookie; la preferencia de idioma se guarda en este navegador. Evita registrar datos sensibles o información personal de terceros.

Si se configura un proveedor de IA, la descripción ingresada se envía a ese proveedor al solicitar una sugerencia. El correo se envía solo si existe un servidor SMTP configurado. Estas integraciones dependen de la configuración del administrador. Antes de un uso institucional real se debe definir responsable, retención de datos y canal para ejercer derechos.

Términos del prototipo

FixCampus es un proyecto académico, sin garantía de atención ni plazos de servicio. Utilízalo para reportes veraces sobre infraestructura. No es un canal de emergencias: utiliza los canales de seguridad de tu campus cuando sea necesario.

Las sugerencias de IA deben revisarse antes de guardar. No existe afiliación ni certificación de Naciones Unidas. El uso institucional requiere aprobación, políticas y configuración propias.
